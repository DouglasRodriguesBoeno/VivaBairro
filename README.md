# VivaBairro — Protótipo interativo (AP2)

Protótipo navegável de alta fidelidade de um portal de oficinas comunitárias, desenvolvido como trabalho acadêmico para a disciplina **Laboratório de Simulação e Prototipagem** (ULBRA).

> **Projeto demonstrativo:** a associação comunitária, as oficinas, datas e vagas apresentadas são fictícias. Nenhuma inscrição é efetivada em uma organização real.

## Objetivo

Demonstrar a experiência de um participante ao pesquisar oficinas, consultar detalhes, simular uma inscrição e acompanhar o comprovante. Inclui também uma visualização ilustrativa para a equipe organizadora.

## Funcionalidades demonstradas

- Catálogo de oficinas com campo de busca e filtros por tema.
- Página de detalhes de cada oficina.
- Formulário de inscrição com validação básica e consentimento.
- Confirmação com protocolo ilustrativo.
- Área de consulta e cancelamento de inscrições locais.
- Painel demonstrativo da ocupação das oficinas.

## Como abrir

Abra o arquivo [`index.html`](index.html) em um navegador moderno. Não é necessário instalar dependências nem iniciar servidor. Para hospedar, é possível utilizar o **GitHub Pages**, servindo o arquivo `index.html` diretamente da raiz do repositório.

## Limitações e privacidade

**É um protótipo, não um sistema de inscrições real.** Não há backend, autenticação, envio de e-mails ou base de dados compartilhada. Os dados preenchidos ficam armazenados no `localStorage` do navegador que estiver usando a demonstração. Para testar, use dados fictícios; não cadastre informações pessoais reais.
